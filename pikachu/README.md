# ⚡ Pokémon Themed CV / Portfolio Templates

A collection of clean, lightweight, and customizable developer resume/CV templates built with semantic **HTML5**, **CSS3**, and **vanilla JavaScript**, themed after iconic Pokémon.

Designed for developers, tech enthusiasts, and designers looking to showcase a creative, gamified personal portfolio.

---

## 🎮 Features

- **Iconic Pokémon Themes**:
  - ⚡ **Pikachu Edition**: High-voltage yellow and electric red aesthetics with interactive shock animations.
  - 💤 **Snorlax Edition**: Heavy-duty teal, cream, and rest/hyper-beam stamina interaction.
- **Zero Dependencies**: Pure HTML5, CSS3, and modern Vanilla JavaScript (no heavy frameworks or build tools required).
- **Responsive & Clean**: Well-structured layout suited for web portfolio showcases and PDF-friendly printing.
- **Ready for GitHub Pages**: Plug-and-play setup ready to be deployed instantly.
- **Privacy Safe & Generic**: Built entirely with modular placeholders for easy personalization.

---

## 📁 Project Structure

```text
├── index.html       # Main HTML template with semantic sections & placeholders
```

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/your-username/pokemon-cv-template.git
cd pokemon-cv-template
```

### 2. Open locally
Simply open `index.html` in your browser, or use VS Code's **Live Server** extension.

### 3. Customize Your Data
Edit `index.html` and replace all bracketed placeholders with your personal information:
- `[TU NOMBRE / TRAINER NAME]`
- `[TU ROL / ESPECIALIDAD]`
- `[POKÉDEX ENTRY / BIO]`
- `[SKILL TREE / MOVESET]`
- `[MAIN QUESTS / EXPERIENCIA]`
- `[SIDE QUESTS / EDUCACIÓN]`

## 🌐 Deploy to GitHub Pages

1. Push your customized template to a GitHub repository.
2. Navigate to **Settings** > **Pages**.
3. Under **Source**, select `Deploy from a branch` and choose `main` / `/ (root)`.
4. Click **Save** — your Pokémon CV will be live at `https://your-username.github.io/pokemon-cv-template/`.
